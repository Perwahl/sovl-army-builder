# SOVL Army Builder

The army builder from [SOVL](https://store.steampowered.com/app/1870300/), running in the browser:
**https://perwahl.github.io/sovl-army-builder/**

Every faction is available. Lists are saved in your browser. Phones and tablets get their own build
(touch layout, mobile texture formats), picked automatically.

This repository only hosts the site: the `gh-pages` branch holds the current build and is replaced on every
release. The game itself is developed elsewhere.
